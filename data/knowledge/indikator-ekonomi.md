# Indikator Ekonomi Utama

Beberapa indikator ekonomi yang rutin dirilis BPS:

- **Inflasi:** perubahan IHK bulanan/tahunan.
- **PDRB / PDB:** output ekonomi regional/nasional (ADHB dan ADHK).
- **Ekspor-impor:** nilai perdagangan luar negeri bulanan.
- **Ketenagakerjaan:** tingkat pengangguran terbuka, angkatan kerja.
- **Kemiskinan:** persentase penduduk miskin per wilayah.
- **IPM:** Indeks Pembangunan Manusia.

## Parameter untuk angka

Setiap indikator memerlukan:

- **Wilayah:** Indonesia/provinsi/kabupaten/kota.
- **Periode:** tahun/triwulan/bulan.
- **Varian:** ADHB/ADHK untuk PDRB; bulanan/tahunan untuk inflasi.

## Catatan

Demo ini tidak menampilkan angka aktual yang belum diverifikasi. Bila parameter
belum lengkap, sistem meminta klarifikasi. Lihat situs resmi BPS untuk data
terverifikasi.
